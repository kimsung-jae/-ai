# 보글사다리 Shape AI V2

- 패키지: `com.bubbleladder.shapeaiv2`
- API: 기존 보글사다리3 API 스냅샷 누적, 최근 최대 480회
- 삼치기 없음
- 좌/우, 사다리수, 홀/짝을 각각 독립 분석
- 각 항목: 3칸 메인 60% + 4칸 보조확인 25% + 5칸 보조 15%
- 모양은 값 자체가 아니라 `유지/반전` 전이로 코드화하여 좌우반전된 동일 모양도 같은 패턴군으로 학습
- 완전 모양 + 1전이 차이 유사모양(가중치 0.35)
- 저표본은 50% 쪽으로 축소
- 70% 이상 후보 중 가장 높은 항목 1개만 최고1픽
- 미래누설 없는 Rolling 순차 재현검증
- 백그라운드 자동추첨, 성적 초기화, 전체 초기화, JSON 백업/복원

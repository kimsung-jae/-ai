# 보글사다리 Shape AI V2.1 - 실행오류 수정판

## V2.1 핵심 수정
- 첫 실행 시 백그라운드 자동추첨 기본값 OFF
- 앱 시작과 동시에 Foreground Service를 강제 실행하지 않음
- 사용자가 화면에서 자동추첨 ON을 누른 뒤에만 서비스 시작
- Android 13+ 알림 권한 허용 후 자동추첨 시작
- 서비스 시작 실패 시 앱 전체가 종료되지 않고 자동추첨만 OFF 처리
- 백그라운드 동기화/화면 갱신 예외가 발생해도 앱 프로세스가 죽지 않도록 방어 처리
- Android 15+ dataSync Foreground Service 시간 제한 시 onTimeout에서 정상 종료
- 시스템이 서비스를 강제로 죽인 뒤 임의 재시작하지 않도록 START_NOT_STICKY
- 이전 V2와 설치/서명 충돌을 피하기 위해 독립 패키지 사용

## 패키지
`com.bubbleladder.shapeaiv21`

## 분석 엔진
- API 스냅샷 누적, 최근 최대 480회
- 삼치기 없음
- 좌/우, 사다리수, 홀/짝 독립 분석
- 3칸 메인 60% + 4칸 보조확인 25% + 5칸 보조 15%
- 값 자체가 아닌 `유지/반전` 전이 모양 학습
- 완전 모양 + 1전이 차이 유사모양(가중치 0.35)
- 70% 이상 후보 중 가장 높은 항목 1개만 최고1픽
- 미래누설 없는 Rolling 순차 재현검증

## 설치 후
1. 앱을 먼저 실행해 화면이 정상적으로 열리는지 확인
2. `지금 수집 / 모양 AI 분석` 버튼으로 수동 수집 확인
3. 그 다음 `백그라운드 자동추첨 ON` 체크
4. 알림 권한 요청이 나오면 허용
